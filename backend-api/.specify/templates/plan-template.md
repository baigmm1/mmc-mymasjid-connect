## Dependency Management _(Python Projects Only)_

**Pattern**: `requirements.in` (source) → `pip-compile` → `requirements.txt` (generated)

### requirements.in

- Lists only **direct dependencies** with explanatory comments
- Human-readable and maintainable
- Example:
  ```
  # Web framework
  fastapi==0.104.1
  # JSON logging
  python-json-logger==2.0.7
  ```

### requirements.txt

- Auto-generated by `pip-compile requirements.in`
- Contains full dependency tree with transitive dependencies
- Each package shows which packages depend on it
- Ensures reproducible builds across environments

**Workflow**:

1. Update `requirements.in` when adding/removing direct dependencies
2. Run: `pip-compile requirements.in`
3. Commit both `requirements.in` and `requirements.txt`
